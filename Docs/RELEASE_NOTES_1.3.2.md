# GP-SDR 1.3.2

This maintenance release keeps Mapper configuration state consistent when
editing saved jobs.

- Saved Mapper jobs now restore the **Use all connected receivers** setting
  when loaded, including the disabled single-receiver selector state.
- Version and release documentation are aligned at 1.3.2.

The 1.3.1 multi-receiver fan-out, numbered duplicate-device labels, bounded
Mapper rendering, and receive-only hardware validation remain included.
