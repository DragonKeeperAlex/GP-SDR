# GP-SDR 1.0.2

This maintenance release completes the GP-SDR rename across source code,
packaging, configuration names, helper discovery, documentation, and compiled
artifacts. Obsolete compatibility aliases from the former project name were
removed so new builds contain GP-SDR branding exclusively.

Google Sheets range synchronization, the bundled P25 stack, regional profiles,
bulk channel imports, and all 1.0.1 features remain included.
